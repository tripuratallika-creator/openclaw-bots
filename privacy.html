Privacy Policy

Last updated: September 2026

OpenClaw Bots is a private, single-user automation assistant operated by Tripura Tallika. It is not offered to the public and has no other users.

What data is accessed

With the owner's explicit authorization, the application accesses the owner's own Google account data: Gmail messages, Google Calendar events, and Google Drive files. It accesses no one else's data.

How data is used

Data is used only to carry out tasks the owner requests, such as reading and drafting the owner's email, checking the owner's calendar, and reading the owner's documents.

Sharing and retention

Data is not sold, rented, or shared with third parties. It is not used for advertising or profiling. It is processed only for the duration of a request and is not retained in any separate database.

Google user data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke access at any time via the Google Account permissions page.
